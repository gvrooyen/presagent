presagent

Single-page HTML decks. One engine for the keys, notes, presenter window, and audio output. The look belongs to the deck.

  • Night Signal — demo with text, image, video, YouTube, notes, and a custom slide
  • Under the hedge — the same engine, a paper theme
  • Template — copy this to start a deck

Inside a deck, press ? for the controls. Serve this folder with python3 -m http.server 8000 --bind 127.0.0.1 before using the speaker picker.
